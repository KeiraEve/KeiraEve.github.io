# KeiraEve.github.io

A hosting provider for web hosting is a company that rents out the technology and server space that make live websites possible.
You can also host your site by buying the technology and server space yourself, or by using site hosts such as Github Pages.

Github Pages does support custom domain names! This can be found in the Pages section of the Settings, or at https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages
